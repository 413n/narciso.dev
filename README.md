# narciso.dev

Personal site for Alessandro Narciso — a Switzerland-based full stack developer.

The homepage is a split-stage project reel: night/day modes, Motion-driven project switching, and view transitions into each case study. A `/cv` route uses the same visual language.

## Stack

- React 19
- TanStack Start
- Tailwind CSS 4
- shadcn/ui
- Motion

## Commands

```sh
pnpm install
pnpm dev
pnpm build
pnpm check
```
